Seven rituals, one rule: never destroy your work

Each ritual solves one chore developers keep postponing. Type your intent in plain English, or call a ritual by name.

coffinand resurrect
Pick up exactly where you stopped. Saves your branch, the file and line you last edited, a git stash snapshot and an AI summary. aether resurrect --open reopens the files at those lines.
sweepDeadCode Hunter
Finds functions nobody calls. Indexes every reference in the project, then reports calculateTax() at line 45 with a confidence level. Also lists files nothing imports.
exorciseZombie Dependency Exorcist
Finds dead dependencies and rewrites the code that uses them. Reads package.json and requirements.txt, shows every import site, and with --rewrite the AI proposes the migration plus a test.
whisperError Message Translator
Turns cryptic errors into a cause and a fix. Understands 25+ PHP, JavaScript, Python, git and npm errors offline. Pipe any failing command into it.
oathCursed Commit Hook
Blocks "fix bug" and offers three better messages. Installs as a real git hook. Judges meaning, not keywords, so fix: resolve null pointer in AuthController passes.
driftConfig Drift Detector
Keeps every environment in agreement. Compares all .env files and the variables your code reads, and generates a .env.example with secret values always blanked.
asknatural language
Say what you want. aether "save my work, I was fixing the reset token" picks the right ritual, with or without an AI key.

Works offline. Better with AI.

Every ritual has a deterministic local engine. The AI layer (Nebius, any OpenAI-compatible model) only improves the answer, and any failure falls back to the local result.

Without a key

  • coffin writes a summary from your changed files and edit lines
  • sweep, exorcise, drift are fully local static analysis
  • whisper and oath use a built-in grimoire and diff-aware suggestions
  • ask routes with a weighted keyword router

With a key

  • coffin explains what you were trying to do and where you stopped
  • exorcise --rewrite migrates code off dead packages and drafts tests
  • sweep --ai double-checks for dynamic or framework usage
  • drift --ai documents each variable, sending key names only

Where it fits

  • Resurrection: coffin and exorcise bring dead context and dead code back to life
  • Frankenstein: seven tools, git, static analysis and an LLM stitched into one CLI
  • Safe by design: no shell injection, non-destructive snapshots, guarded rewrites, honest confidence levels
  • MCP: aether mcp exposes seven tools, so Kiro itself can freeze and restore its own session
  • Property-based tests: fast-check hammers the engines with random input and already caught a real bug
  • Tested: twelve end-to-end tests plus seven properties

Quick start

Needs Node 18 or newer. No API key required to try every ritual.

# install
git clone https://github.com/YOUR-USERNAME/AETHER.git && cd AETHER
npm install && npm run build && npm link

# optional: enable the AI layer
cp .env.example .env   # then add NEBIUS_API_KEY

# try it
aether "save my work, I was fixing the reset token"
aether resurrect --open
aether sweep && aether drift && aether exorcise
aether oath --install-hook
