# Product: AETHER

AETHER is a terminal companion for developers: seven small "rituals" that remove the tedious, forgotten chores of a codebase.
It is **offline-first** — every ritual has a deterministic local engine — and the AI layer (Nebius, OpenAI-compatible) only *improves* the answer.

| Ritual | Hackathon idea | Promise |
|---|---|---|
| `coffin` / `resurrect` | Cryostasis | Freeze and restore your mental + physical context |
| `exorcise` | Zombie Dependency Exorcist | Find dead dependencies *and rewrite the code that uses them* |
| `sweep` | DeadCode Hunter | Trace references; "calculateTax() at line 45 is never called" |
| `whisper` | Error Message Translator | Cryptic error → plain language + fix |
| `oath` | Cursed Commit Hook | Block lazy commits, offer 3 specific alternatives |
| `drift` | Config Drift Detector | Compare every `.env`; generate a safe `.env.example` |
| `ask` (default) | — | Natural language → the right ritual |

Principles: never destroy user work · never print or send secret values · say honestly when analysis is heuristic.
